# Roadmap — approved A-nanTa 8 pretrained + 7 Quant research plan

| Stage | Scope | Status |
|---|---|---|
| P0 | Repository contracts, data validation, manifest and CI | Existing scaffold; not evidence of model performance |
| P1 | Point-in-time broker/exchange data, timestamps, labels | Planned |
| P2 | Fit MS-AR, Kalman, EGARCH, Statistical Jump Model, BOCPD | Planned |

| P5 | Probability calibration, horizon alignment, regime-aware reporting | Planned |
| P6 | First-Passage / Optimal Stopping and execution-aware costs | Planned |
| P7 | Walk-forward, ablations, untouched holdout, after-cost evaluation | Planned |

Risk, sizing, and execution remain deterministic infrastructure rather than extra model selections. No RL policy, new foundation checkpoints, L2-learning model or unrelated meta-ensemble is part of the approved plan. See [QUANT_MODEL_PLAN.md](QUANT_MODEL_PLAN.md).
